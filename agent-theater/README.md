# Agent theater（評審用，不是乘客 App）

這個 HTML **是** user agent 把一則提案送給仲裁的房間，不是乘客群組聊天。

- 白泡：user agent 送出的 pitch／分數。匿名，只寫 A／B／C／D。
- 紫塊 **Arbiter mind**：仲裁心智。在算跳表、拆帳、多數。不是一個叫 R 的人在群裡說話。
- 乘客 App 只看得到自己那位 agent 的英文劇場。看不到這個房間。

## 價錢怎麼來

1. 每人獨乘：新竹跳表。
2. 共乘總額：`0.72 × 獨乘和`。
3. 按獨乘比拆。最後一人吃 residual。
4. v2 沿 axis／give 微調。4 人要 3 票才採用 v2。
